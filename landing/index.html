— FAQ

Common questions.

Claude Code Max 5시간 한도는 어떻게 추적해요?
Anthropic은 구독 한도용 공식 API를 제공하지 않아요. 대신 Cap의 데스크톱 에이전트가 ~/.claude/projects/**/*.jsonl 로컬 로그를 파싱합니다. 토큰 카운터와 타임스탬프만 업로드, 프롬프트나 코드는 절대 보내지 않아요. Pro 플랜에 포함.
API 키는 안전하게 보관되나요?
키는 폰에서 libsodium secretbox로 암호화돼서 폰을 떠나는 건 ciphertext + key ID뿐입니다. 백엔드는 평문 키를 절대 갖지 않고, KMS(AWS·GCP)에 wrapping key가 격리돼 있어요. TLS 1.3 + 인증서 핀닝.
ccusage 같은 무료 OSS 있는데 왜 Cap을?
ccusage는 훌륭한 도구지만 터미널 기반이에요. Cap의 차별점은 워치 글랜스(잠금 해제 없이 한눈에) + 예측 알림(막히기 전에 푸시) + 두 서비스 통합. 터미널만으로 충분하면 ccusage 추천드려요. 워치/모바일 경험 원하면 Cap.
언제 실제 출시되나요?
현재 비공개 베타. TestFlight + Play Console 내부 테스트를 거쳐 1.0 정식 출시 예정. 웨이트리스트 등록하시면 베타 초대 발송. 출시 6개월간 Plus Lifetime ₩59,000 한정 판매도 진행해요.
Apple Watch 없어도 쓸 수 있나요?
네. Free 플랜은 폰 앱만으로 작동합니다. 워치 컴플리케이션은 Plus 이상 필요하지만, Pro의 데스크톱 에이전트나 예측 알림은 워치 없이도 모두 작동해요.
